# Resume Builder

A simple React application for creating a resume with a live preview.

## Features

- Add general contact information
- Add education details
- Add practical experience and responsibilities
- Preview the resume as you enter information

## Getting started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## Available scripts

- `npm run dev` - start the development server
- `npm run build` - create a production build
- `npm run preview` - preview the production build locally
- `npm run lint` - check the project with ESLint

## Usage

Enter your information in each section and select **Submit**. The resume preview updates with the submitted details. Select **Edit** to change a section.
